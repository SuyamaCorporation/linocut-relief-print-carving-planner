# 木版・リノカット 彫り跡デザインプランナー

リノリウム版や木版の彫り跡パターンをブラウザ上でデザインし、モノクロ・多色重ね刷りをプレビューできるアプリです。SVGベースのキャンバスでフリーハンドや図形ツールを使って版を設計し、印刷イメージをリアルタイムに確認できます。

## 機能
- ブラシ・消しゴム・矩形・円形・直線の描画ツール
- 3レイヤー対応（版1・版2・版3）のカラーモード切替（モノクロ/2色/3色）
- 各版のインク色・紙の色（白/クリーム/グレー/黒）選択
- レイヤー透明度コントロール
- ネガポジ反転プレビュー
- 水平・垂直ミラー描画（文字・ロゴの反転対応）
- ズーム1x/2x
- 各レイヤー個別PNG＋合成PNGダウンロード
